# 姫の寄せ書き帳（princess.html）の保存先の作り方

隠しページで訪問者が「サインして帰る」を押すと、ニックネームとその訪問で押したハートの数が
Google スプレッドシートに1行ずつ記録され、ページに時系列順で並びます。
この仕組みを動かすには、以下を一度だけ行ってください（10分ほどです）。

## 1. スプレッドシートを作る
1. チームで管理している Google アカウントで [Google スプレッドシート](https://sheets.google.com) を開き、新しいシートを作る
   （名前は何でもOK。例：`miRNA Princess guestbook`）

## 2. Apps Script を貼り付ける
1. シートのメニュー **拡張機能 → Apps Script** を開く
2. 最初からある `コード.gs`（`Code.gs`）の中身をすべて消し、このフォルダの [`Code.gs`](Code.gs) の中身を丸ごと貼り付けて保存（💾）

## 3. ウェブアプリとして公開する
1. 右上の **デプロイ → 新しいデプロイ**
2. 種類の歯車から **ウェブアプリ** を選ぶ
3. 次のように設定して **デプロイ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 初回は権限の確認が出るので、自分のアカウントを選んで許可する
   （「このアプリは Google で確認されていません」と出たら **詳細 → (プロジェクト名) に移動** で進めます）
5. 表示される **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピー

## 4. ページに URL を入れる
[`princess.html`](../../princess.html) の次の行の `data-endpoint=""` に、コピーした URL を入れる：

```html
<section class="royal-guestbook" id="princess-guestbook" data-endpoint="ここにURL">
```

これでページに寄せ書き帳が表示されます。URL が空のあいだは「準備中」と表示されます。

## 運用メモ
- 記録はシートの `guestbook` タブに `time / nickname / hearts / hide` の4列で並びます（最初の投稿で自動的に作られます）。
- **不適切なニックネームを隠したいとき**：その行の `hide` 列（D列）に何か文字を入れる。または行ごと削除する。
- ページに表示されるのは最新100件までです（`Code.gs` の `LIST_LIMIT` で変更できます）。
- `Code.gs` を書き換えたときは、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ** で反映します（URL は変わりません）。
