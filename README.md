## VS Codeでコードを変更する場合の手順
- コードの変更をする場合は、事前に鈴置に申告。VScodeをPCにダウンロードし、このレポジトリをcloneしてから進める。

1. **作業前に必ず Pull する**
   - 作業を始める前に、必ず最新の状態を自分のPCに取得（Pull）してください。忘れるとトラブルの原因に。
2. **新しいブランチを作成する**
   - 直接 `main` ブランチで作業せず、必ず自分の作業用ブランチを切ってから作業を始める。
3. **こまめに Commit & Push をする**
   - 作業単位でこまめにコミットとプッシュを行うこと。
4. **分かりやすいコミットメッセージを書く**
   - 何をしたかが一目で分かるように記述。
   - NG例：`a`, `123`, `修正`
   - OK例：`プロジェクトページのレイアウト変更`, `トップページの画像追加`
5. **Force Push は原則禁止**
   - 名前に `force` が付く操作はデータの履歴を破壊するため**絶対に行わないでください**。わからない場合は絶対に実行せず相談。
