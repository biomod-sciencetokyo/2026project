# ２０２６年のwiki

参加者は必ず以下のルールを確認し、守って作業してください。

## 基本ルール
- 文章の変更・画像や動画のアップロードは、このGitHubのWebページ上で行っても構いません。
- コードの変更をする場合は、事前に鈴置に申告してください。

---

## VS Codeでコードを変更する場合の手順

1. **作業前に必ず Pull する**
   - 作業を始める前に、必ず最新の状態を自分のPCに取得（Pull）してください。忘れるとトラブルの原因になります。
2. **新しいブランチを作成する**
   - 直接 `main` ブランチで作業せず、必ず自分の作業用ブランチを切ってから作業を始めてください。
3. **こまめに Commit & Push をする**
   - 作業単位でこまめにコミットとプッシュを行ってください。
4. **分かりやすいコミットメッセージを書く**
   - 何をしたかが一目で分かるように記述してください。
   - NG例：`a`, `123`, `修正`
   - OK例：`プロジェクトページのレイアウト変更`, `トップページの画像追加`
5. **Force Push は原則禁止**
   - 名前に `force` が付く操作はデータの履歴を破壊するため**絶対に行わないでください**。わからない場合は絶対に実行せず、鈴置に相談してください。

---

## トラブルが起きたら
- エラーが出た、コンフリクトしてしまった、何をしたらいいか分からなくなった場合は、**自己解決しようとせず、焦らずにすぐ鈴置へ連絡**してください。
