1.2 One-run Numerical Procedure

  1. Initialize a periodic membrane ring and one 12-chain DNA Bundle. The documented Bundle uses five connected constant-curvature arcs and length LBundle = 3R.
  2. Apply the model's approach drive to bring the DNA Bundle toward the membrane. The drive schedule, initial coordinates, and magnitude are not recorded in this repository.
  3. Evaluate membrane spring, contour-smoothing, area-restoring, linker, anchor-reaction, and DNA–membrane repulsion terms using the documented settings.
  4. Advance membrane beads and captured cholesterol particles using the overdamped Brownian update. Update the Bundle's eight generalized coordinates with the documented semi-implicit linear system.
  5. At each substep, inspect intact membrane springs. Register the first local event if any spring satisfies Ti > 150.
  6. After registration, the documented procedure removes the planar area-restoring term in subsequent updates. Whether an individual run stops at that point is not specified in the repository.

1.3 Stochastic Reproducibility

The Simulation page documents n = 50 trajectories per parameter cell for the aligned R = 150/200 nm sweep. It also says the single-trajectory GIF settings accept a seed. However, the repository contains no seed policy, per-run seed list, script version, heatmap-specific settings, or output CSV. The six displayed heatmap radii (50–300 nm) therefore cannot be tied to the documented sample size or to a reproducible run manifest from the checked-in files.

For a reproducible release, preserve and publish at least:

  • the simulator source revision or immutable script hash;
  • the master seed and the mapping from parameter cell and replicate to each seed;
  • R, BDNA, l0, all fixed settings, Δt, frame and substep counts, and any initialization/drive settings;
  • the output CSV row or file corresponding to each seed and parameter cell, including event status and event substep/time when available; and
  • the aggregation rule used to convert replicate outcomes to each heatmap cell.

1.4 Numerical Checks and Limits

The documented membrane discretization gives an initial spacing of approximately 3.927 nm at R = 150 and 200 nm. This is a geometric property of the stated discretization rule, not evidence of convergence.

No reproducible convergence or sensitivity results are included for time step, membrane segmentation, DNA–membrane repulsion evaluation-point count, or observation duration. Those checks remain future validation, not established results.

The website repository does not include simulator source, test logs, or run outputs with which to independently reproduce additional numerical checks.

2. 3D Reduced Free-Energy Model

For the R0 = 50 nm reference condition, a constrained reduced free-energy model optimizes indentation depth zindent, Bundle bend radius Rbend, and deformation-pocket width wy. Its objective includes aggregate cholesterol adhesion, DNA Bundle bending, and an approximate membrane bending/tension penalty. A static parametric membrane indentation is constructed from the optimized quantities and exported as a rotatable GLB visualization. This is a qualitative deformation/local-curvature comparison, not a dynamic membrane simulation or a full Helfrich shape minimization; pore formation and rupture are outside the claims of this model.

The stated objective is Ftotal = Eadhesion + EDNA bend + Emembrane. The documented beam contribution is EDNA bend = ½BDNA(1/Rbend)2LBundle. Cholesterol adhesion is represented as an aggregate term: individual cholesterol positions and linkers are not explicitly resolved in 3D.

The GLB's local curvature is calculated from the parametric mesh after optimization, with H = |H| and display clipping to 0.015–0.075 nm−1; the color scale spans 0.018–0.065 nm−1. These colors show a qualitative local-curvature distribution. They are not the optimization target, an average-curvature result, or a threshold-exceedance/rupture measurement.

2.1 Optimization Procedure and Boundary-Limited Result

  1. The stated objective is the sum of cholesterol-anchor adhesion, DNA Bundle bending, and an approximate membrane bending/tension penalty.
  2. The stated optimization variables are indentation depth zindent, Bundle bend radius Rbend, and deformation pocket width wy. L-BFGS-B starts from [4.0, 50.0, 6.0] with bounds [0.5, 35, 3.2] to [7.2, 250, 12] nm.
  3. The current result, [7.2 nm, 250 nm, 12 nm], is at the upper bound for all three variables.

The current result is a minimum within the prescribed bounds. Because all optimized variables reach their upper bounds, it should be interpreted as a directional tendency of the present ansatz rather than as a uniquely determined equilibrium geometry.

Phenomenological Helix-Count Scaling Analysis

The graphs on the Simulation page are a separate phenomenological helix-count scaling analysis, not output of the 3D indentation optimization. For R0 = 50 nm and Lbundle = 60 nm, they illustrate how the assumed effective-rigidity scaling Beff ∝ αN2 shifts the manually selected comparison level Hcrit = 0.067 nm−1: the crossings are approximately 6 helices for α = 1.0, 8.5 for α = 0.5, and 19 for α = 0.1. Here α is a phenomenological effective-rigidity coefficient, not a measured cross-linking efficiency; these crossings are scaling comparisons, not evidence that pores form or membranes rupture.

4. Multi-Bundle Extension and Limitations

The 3D implementation can set the number of independent DNA Bundles with SIM_NUM_BUNDLES. In the current multi-Bundle extension, Bundles are arranged as an independent parallel array and their free-energy contributions are added independently. Bundle–Bundle interactions, membrane-mediated cooperativity, and overlap-dependent mechanics are not yet included. This extension is not direct evidence that multiple Bundles enhance membrane rupture.
