1.2 One-run Numerical Procedure

  1. Initialize a periodic membrane ring and one 12-chain DNA Bundle. The documented Bundle uses five connected constant-curvature arcs and length LBundle = 3R.
  2. Apply the model's approach drive to bring the DNA Bundle toward the membrane. The drive schedule, initial coordinates, and magnitude are not recorded in this repository.
  3. Evaluate membrane spring, contour-smoothing, area-restoring, linker, anchor-reaction, and DNA–membrane repulsion terms using the documented settings.
  4. Advance membrane beads and captured cholesterol particles using the overdamped Brownian update. Update the Bundle's eight generalized coordinates with the documented semi-implicit linear system.
  5. At each substep, inspect intact membrane springs. Register the first local event if any spring satisfies Ti > 150.
  6. After registration, the documented procedure removes the planar area-restoring term in subsequent updates. Whether an individual run stops at that point is not specified in the repository.

1.3 Stochastic Reproducibility

The Simulation page documents n = 50 trajectories per parameter cell for the aligned R = 150/200 nm sweep. It also says the single-trajectory GIF settings accept a seed. However, the repository contains no seed policy, per-run seed list, script version, heatmap-specific settings, or output CSV. The six displayed heatmap radii (50–300 nm) therefore cannot be tied to the documented sample size or to a reproducible run manifest from the checked-in files.

For a reproducible release, preserve and publish at least:

  • the simulator source revision or immutable script hash;
  • the master seed and the mapping from parameter cell and replicate to each seed;
  • R, BDNA, l0, all fixed settings, Δt, frame and substep counts, and any initialization/drive settings;
  • the output CSV row or file corresponding to each seed and parameter cell, including event status and event substep/time when available; and
  • the aggregation rule used to convert replicate outcomes to each heatmap cell.

1.4 Numerical Checks and Limits

The documented membrane discretization gives an initial spacing of approximately 3.927 nm at R = 150 and 200 nm. This is a geometric property of the stated discretization rule, not evidence of convergence.

No reproducible convergence or sensitivity results are included for time step, membrane segmentation, DNA–membrane repulsion evaluation-point count, or observation duration. Those checks remain future validation, not established results.

The website repository does not include simulator source, test logs, or run outputs with which to independently reproduce additional numerical checks.

2. 3D Thermodynamic Model

The documented equilibrium calculation minimizes adhesion, DNA Bundle bending, and membrane deformation energies for an R0 = 50 nm reference liposome. It is separate from the large-GUV discussion and does not simulate dynamic pore formation or membrane rupture.

The stated objective is Ftotal = Eadhesion + EDNA bend + Emembrane. The documented beam contribution is EDNA bend = ½BDNA(1/Rbend)2LBundle. The model description says adhesion scales with the contact area; the exact implemented membrane and contact-area expressions are not included in the repository.

2.1 Optimization Procedure: Known and Unreported

  1. The stated objective is the sum of cholesterol-anchor adhesion, DNA Bundle bending, and membrane bending/tension contributions.
  2. The stated optimization variables are indentation depth zindent, Bundle bend radius Rbend, and deformation width wy.
  3. The Simulation page names SciPy L-BFGS-B as the optimizer. It does not report initial values, bounds, tolerances, stopping conditions, or how competing solutions were compared.
  4. The repository has no 3D calculation code or optimization logs. These missing details are not inferred here and must be recorded before the optimization can be independently reproduced.
